# Roadmap

This roadmap communicates direction, not delivery commitments. Detailed work
will be tracked through GitHub issues and milestones.

## Phase 1: foundations

- Define the ASPM domain model and stable identifiers
- Publish architecture and threat model
- Establish API, authentication, and integration contracts
- Add local development, testing, and release automation

## Phase 2: ingestion and inventory

- Add application, repository, artifact, and environment inventory
- Define a versioned finding ingestion contract
- Build the first scanner and source control integrations
- Preserve source evidence and ingestion provenance

## Phase 3: posture management

- Correlate and deduplicate findings
- Add ownership and remediation workflows
- Implement risk-based prioritization and policy evaluation
- Expose stable API and CLI interfaces

## Phase 4: operations

- Add dashboards, audit trail, and reporting
- Document backup, upgrade, and production deployment procedures
- Establish compatibility and support policies
