# open-aspm
Open-source Application Security Posture Management platform for aggregating, correlating, prioritizing, and tracking security findings across the SDLC.
 # Project Name

  Open-source Application Security Posture Management platform.

  > Status: early development / pre-alpha. Not ready for production use.

  ## Why

  Security findings are fragmented across SAST, SCA, DAST, secrets,
  container, cloud, and infrastructure scanners. The project provides
  a unified model for correlating, prioritizing, assigning, and tracking them.

  ## Planned capabilities

  - Scanner and repository integrations
  - Finding normalization and correlation
  - Deduplication
  - Asset and application inventory
  - Risk-based prioritization
  - Policy and Security Gate evaluation
  - Suppression and risk acceptance workflows
  - CI/CD integration
  - API and CLI
  - Audit trail and reporting

  ## Non-goals

  - Replacing source security scanners
  - Automatically fixing vulnerabilities without review
  - Claiming compliance based only on imported findings

  ## Project status

  The architecture and data model are currently under development.
  Interfaces may change before the first stable release.
